# 指定したフォルダの書類を分析する（読むだけ）

## はじめに確かめること
- 分析するフォルダは、**人がこの会話で指定したフォルダだけ**。指定がなければ聞く。
- このスキルでは、ファイルの移動・名前の変更・書き換えを一切しない。

## 手順
1. 指定フォルダの中のファイルを一覧にする（小フォルダも含める）。種類（拡張子）ごとの件数を数える。
2. 1件ずつ中身を読み、次を表にまとめる：ファイルの場所／書類の種類／取引先／書類の日付／金額（税込）／期限。読めないところは「不明」。
   - Excel・CSVは、表の見出しと行数、合計できる金額の列を確かめる。表が売上や経費の一覧なら、その合計も出す。
   - Wordは、題名と要点（3行まで）を書く。
3. 次のことを計算・確認する。数字は書類から読み取ったものだけで計算し、推測しない。
   - 書類の種類ごとの件数
   - 取引先ごとの件数と金額の合計（多い順に10社）
   - 月ごとの金額の合計（請求書・領収書など、種類ごとに分ける）
   - 今日から60日以内の期限（過ぎたものも含めて、近い順）
   - 同じ中身・同じ名前のファイル（重複の疑い）
   - 1年以上更新されていないファイルの数
   - 個人情報（マイナンバー・口座番号など）を含む疑いのあるファイル（場所だけ。中身は書かない）
4. 指定フォルダの中に「分析レポート_YYYY-MM-DD.md」を作る。構成：
   - はじめに（何件・どの期間の書類か、3行で）
   - 気をつけること（期限が近い・期限切れ・重複・個人情報）
   - 数字のまとめ（上の表）
   - 次にできること（例：「/folder-tidy で整理できます」「売上の一覧は /tidy-csv で売上台帳に入れられます」）
   - 読めなかったファイルの一覧
5. 会話では、レポートの要点を5行で伝え、「レポートを保存しました：（場所）」と知らせる。

## 守ること
- 読むだけ。ファイルを動かさない・変えない・消さない（レポートを1つ作るだけ）。
- 個人情報の中身はレポートに書き写さない。
- 推測した数字は書かない。合計できないものは「合計できない（理由）」と書く。
