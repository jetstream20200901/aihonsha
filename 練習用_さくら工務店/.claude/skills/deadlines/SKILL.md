# 期限の確認

## 手順
1. 今日の日付を確かめる。日数の指定がなければ60日とする。
2. 次の3つから期限を集める。
   - 台帳/書類台帳.csv の「期限」（書類の種類・取引先・メモと一緒に）
   - 台帳/売上台帳.csv で「入金日」が空の行の「入金期限」（入金待ち）
   - 台帳/やること.csv で「状態」が「済」でない行の「期限」
3. 期限を過ぎたものを先頭に、残りは期限の近い順に並べ、表で見せる：期限・残り日数（過ぎていれば「○日過ぎ」）・何の期限か・相手・金額。
4. 最後に「過ぎている○件・7日以内○件・期間内○件」とまとめる。

## 毎朝の自動確認（知らせてほしいとき）
自分で頼まなくても毎朝知らせてほしいときは、Claude アプリの Code タブで、この会社フォルダを開いて次のように頼む。
「毎朝8時に、deadlines の手順で期限を確認して。過ぎているものと7日以内のものだけを短く報告して。無ければ『今日の期限の知らせはありません』とだけ書いて」
→ Claude が「スケジュールタスク」を作り、毎朝その時間に自動で確認する（パソコンと Claude アプリが起動している必要がある）。結果はタスクの実行結果としてアプリに残る（通知の出方はアプリの設定による）。
自動確認のときは、上の手順3の表を「過ぎているもの」「7日以内」だけにして短くする。

## 守ること
- 台帳は読むだけで変えない。
