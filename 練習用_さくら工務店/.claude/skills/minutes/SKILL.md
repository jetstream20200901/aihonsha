# 議事録の清書

## 手順
1. 渡されたメモ（貼り付けた文、または 20_議事録 のファイル）を読む。
2. 次の形に清書する。
   - 会議名／日時／場所／参加者
   - 決まったこと（箇条書き）
   - 宿題（誰が・何を・いつまでに）
   - 話し合ったこと（要点だけ）
   - 次回（日時・議題）
3. メモに無いことは書かない。わからない所は「（未確認）」と書く。
4. 20_議事録/YYYY-MM-DD_会議名_議事録.md に保存する（日付は会議の日）。
5. 宿題を表で見せ、「やること台帳に足しますか？」と聞く。OKなら 台帳/やること.csv に「期限,内容,担当,状態（未）」で書き足す。
