# 毎日の議事録（AI本社の1日のまとめ）

**トークン節約**：読むのはその日の分だけ。全部の台帳を読み直さない。動きの無い日は短く書いて終わる。

## 1. 読むもの（その日＝今日。朝の確認から呼ばれたときは「きのう」）
- 台帳/部署の記録.csv の、その日の行（社長の判断「○○（社長OK）」もここにある）
- 箱/依頼箱.json の、その日に頼まれた・済になったもの
- 台帳/判断待ち.json の、まだ答えのないもの（件数と上から3件）
- 台帳/経営.json の pdca（周・段階・課題）だけ
- 台帳/やること.csv の、期限が明日から3日以内のもの

## 2. 書く形
`20_議事録/AI本社/YYYY-MM-DD_AI本社_議事録.md`（日付はその日）に保存する。
```
# AI本社 議事録（YYYY-MM-DD・曜日）
- 会議：AI本社の1日のまとめ（AIが自動で記録）
- 出席：その日に動いた部署（例：事務・経理・営業）／進行：AI社長室

## ひとことで
（その日の一番大事なことを1行。画面のホームにそのまま出る）

## 社長が決めたこと
- ○○ → OK（実行を始めた）

## 各部署の報告
### 事務
- やったこと：…
- 次の予定：…

## 社長にお願いしたいこと
- 判断待ち ○件（上から3件を1行ずつ）

## PDCA
- ○周目・段階 ○（○日目）・課題：…

## 明日からの予定・期限
- MM-DD ○○
```
- 動きが無かった日は「## ひとことで」に「きょうは動きがありませんでした」と書き、ほかの見出しは「なし」で終える。
- 書いてあること以外は書かない。数字は台帳にあるものだけ。
- パスワード・口座番号・マイナンバー・カード番号・個人の健康のことは書かない。

## 3. 守ること
- その日のファイルがもうあれば、上書きせず最後に「## 追記（HH:MM）」として足す。
- 社長が確認したかどうかは画面が 台帳/議事録の確認.json に書く。AIはここを書き換えない。
- 部署の記録.csv に「日付,事務,AI本社の議事録を作成,」を1行書く。/dashboard はしない。
- 報告は「議事録を保存しました（ファイルの場所）」の1行だけ。
