# 資金繰り

**計算は画面がする**（画面/dashboard.html の「💴 資金繰り」。台帳から自分で計算するのでAIは要らない）。この手順は、計算の材料を正しく保つことと、足りないときの対策を考えることだけ。

## 計算のしかた（画面と同じ。フォルダとつながっていないときの写しを作るときも同じ）
- はじめの残高：台帳/お金.json の balance（3日以内に取ったもの）、なければ 設定.json の balance
- 入金：売上台帳で入金日が空の行を、入金期限の日に（期限を過ぎたものは入れず、別に金額を示す）。会計ソフトの receivable_items があればそちら
- 出金：設定の fixed_pay（毎月の決まった支払い）／書類台帳で種類が「請求書」かつメモに「支払う請求書」があり（＝届いた請求書）、「支払済」が無いものを期限の日に／台帳/入出金の予定.csv（日付,内容,入金,出金,メモ）／設定の cf_avg_expense が true なら、直近3か月の「領収書・経費」の月平均（今月は残りの日数分）
- 売上の見込み（まだ請求していないもの）は入れない（かための見込み）
- 安全ライン：設定の cf_safety、空なら決まった支払い1か月分

## 1. 材料を整える
- 届いた請求書を払ったと分かったら（会計ソフトの数字・社長の話・振込の控え）、書類台帳のその行のメモに「支払済」を足す（台帳の書き換えなので、設定で任されていなければ先に一覧を見せる）
- 書類から分かる大きな入出金（税金の通知・賞与・借入の返済予定・前金の約束など）は、台帳/入出金の予定.csv に足す案を出す
- 口座残高を入れた日（設定の balance_date）が7日より古く、会計ソフトもつないでいないときは、判断待ちに「口座残高を入れ直してください（設定 → お金）」を1件

## 2. 足りない月があるとき
月末の残高がマイナス、または安全ラインを下回る月があれば、台帳/判断待ち.json に kind「お金」で1件出す（id は cf-YYYYMMDD）：
- text：「○月末に残高が ○円 まで減る見込み。案：①期限切れ・近い入金の催促（○社 ○円）②支払日の相談（○○ ○円）③金融機関への相談の準備（必要な資料をそろえる）」
- 数字は台帳から計算したものだけ。借入れや投資を勧めない（決めるのは社長。専門家への相談をすすめる）
- 同じ月の件がまだ判断待ちにあれば、足さずに数字だけ直す

## 守ること
- お金を動かさない・振込をしない・会計ソフトに書き込まない
- 口座番号・暗証番号は書かない
- /dashboard はしない（画面が自分で計算する）。部署の記録.csv に「経理：資金繰りを確認（○月末 ○円）」を1行
