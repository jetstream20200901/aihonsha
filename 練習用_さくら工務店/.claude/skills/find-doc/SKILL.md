# 書類を探す

## 手順
1. 台帳/書類台帳.csv を読む。
2. 頼まれた条件（取引先・書類の種類・期間・金額など）で行を絞る。取引先は部分一致で探す（「山田」で「山田商事」も見つける）。
3. 見つかった書類を、書類の日付の新しい順に表で見せる：書類の日付・種類・取引先・金額・期限・ファイルの場所。
4. 期限が過ぎているもの、30日以内のものには印（⚠）を付ける。
5. 台帳に無ければ、会社フォルダの中をファイル名で探し、見つかれば「台帳に載っていない書類があります。/intake で台帳に入れますか？」と聞く。
6. どこにも無ければ「見つかりませんでした」と答え、受付箱に入れ忘れていないか確かめるよう伝える。

## 守ること
- 探すだけで、ファイルを移さない・変えない。
