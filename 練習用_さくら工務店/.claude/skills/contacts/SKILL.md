# 連絡先

台帳/連絡先.json（{"contacts":[…]}）に登録する。1件の形：
```json
{"id":"c+数字","kind":"取引先|銀行|収入元|その他","name":"会社・銀行・サービスの名前","person":"担当者・部署","email":"","phone":"","url":"","address":"","memo":"","source":"手で登録|名刺 YYYY-MM-DD|ネット YYYY-MM-DD（URL）","created":"YYYY-MM-DD HH:MM"}
```
- 取引先名の書き方は CLAUDE.md の決まり（「株式会社」などを外す）。ただし名刺やネットの正式名は memo に「正式名：株式会社○○」と残す。
- **口座番号・暗証番号・パスワード・カード番号・マイナンバーは、名刺や画面にあっても書かない**（見つけたら社長に知らせる）。銀行は「銀行名・支店・担当者・電話・メール・サイト」だけ。
- 収入元（YouTube・Amazon・BOOTH・note など）は、名前・管理画面のURL・問い合わせ先・支払い日（memo）を入れる。

## 登録の3つの方法
1. **手で**：画面の「手で登録」は画面が直接台帳に書く（AIは何もしない）。会話で「○○を入れて」と言われたら、内容を確かめてから台帳に足す。
2. **名刺から**：00_受付箱/名刺 の画像を読み、会社名・担当者・部署・メール・電話・住所・サイトを読み取る。読めない所は「不明」。同じ会社・同じメールがすでにあれば「更新の案」にする。
3. **ネットで調べて**：会社やサービスの**公式のホームページ**など公開情報を調べ、住所・代表電話・問い合わせ用メール・サイトを集める。出どころのURLを source に入れる。個人のSNSやうわさは使わない。確かめられないものは空にする。

2と3は**すぐ登録しない**。台帳/判断待ち.json に kind「登録」で1件ずつ出す（text に「登録の案：名前／担当／メール／電話（出どころ）」、id は reg-YYYYMMDD-連番、案の中身を "data" に入れる）。/inbox で OK が来たら連絡先.json に足し、名刺の画像は 90_その他/名刺_登録済み に移す。

## メールの下書き
1. 宛先の連絡先、用件、ていねいさ、伝えたいことを確かめる。決まりは /reply と同じ（言いにくい連絡も、失礼なく短く）。設定.json の mail_signature を最後に付ける。
2. 台帳/メール下書き.json の drafts に足す：{"id":"m+数字","contact_id","to","to_name","subject","body","created","status":"下書き"}
3. **送らない**。画面の「メールソフトで開く」で、社長の仕事用メール（設定の work_email・mail_client）が開き、社長が確かめて送る。社長が「送った」を押すと status が「送った」になる。
4. 請求書・見積書を添えるメールは、本文に「添付：○○（ファイルの場所）」と書き、添付は社長がメールソフトで付ける。

## 最後に
画面は台帳を自分で読み直すので、ここで /dashboard はしない（写しは朝の確認で1回）。部署の記録.csv に「事務：連絡先○件の案を作成」などを1行書く。
