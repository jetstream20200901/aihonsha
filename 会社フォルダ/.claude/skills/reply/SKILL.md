# メールの返信の下書き

## 手順
1. 相手のメール（貼り付け）と、こちらが伝えたいこと（答え・条件）を確かめる。伝えたいことがわからなければ、先に1つだけ聞く。
2. 丁寧さの指定がなければ「ふつう（ビジネスの丁寧語）」にする。
3. 形：宛名 → あいさつ1行 → 結論 → 理由・補足 → 次にしてほしいこと → 結び。全体は短く。
4. 催促・お詫びのときは、相手を責める言い方をしない。入金の催促は「行き違いでしたらご容赦ください」を入れ、入金予定日を聞く形にする。
5. 件名の案を1つ付ける。
6. 「下書きです。送る前に読んで直してください」と添える。

## 守ること
- メールを送らない。
- 約束していない日付・金額・条件を書き足さない。
