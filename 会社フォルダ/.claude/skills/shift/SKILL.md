# シフトを作る

## 使う表（人事フォルダ）
- 従業員.csv：名前,働き方,できる勤務（日勤・夜勤 など「・」区切り）,週の上限日数,連続勤務の上限,メモ
- 勤務の型.csv：区分,記号,開始,終了,休憩分,必要人数（平日）,必要人数（土日祝）
- シフト希望.csv：名前,日付,希望（休み／日勤だけ／夜勤だけ）,メモ
- 祝日.csv：日付,名前（その月の祝日を入れておく）

## 頼まれ方ごとの手順
### A. 希望や従業員を足す・直す（例：「田中さんは11月20日休み」「パートの小林さんを追加、日勤のみ週3日」）
1. どの表に何を足すかを1行ずつ見せる。名前の書き方は従業員.csvに合わせる。
2. OKをもらってから表に書き足す（消さない。直すときは元の行を見せる）。

### B. シフト表を作る（例：「来月のシフトを作って」）
1. 月を確かめる（言われなければ来月）。その月の祝日が祝日.csvにあるか確かめ、なければ足す案を見せる。
2. 表の中身を確かめる：できる勤務が空の人／必要人数が多すぎて人数が足りない見込み（必要な延べ人数と、全員の上限の合計を比べる）を、先に知らせる。
3. このスキルの中の shift.py で作る：`python .claude/skills/shift/shift.py 人事 YYYY-MM`
   - Python が使えないパソコンでは、shift.py の先頭に書いた「決まり」と同じ順番で、日ごとに手で組み、同じ3つのファイルを作る。
4. できた「シフトの確認_YYYY-MM.md」を読み、人が足りない日と守れなかった希望を先に伝える。足りない日は、入れられる人の候補（上限の残りがある人）を出して、人に決めてもらう。
5. 「シフト表_YYYY-MM.html をブラウザで開くと見やすい表になっています」と伝える。

## 決まり（会社に合わせて /fit-company で直せる）
- 夜勤の次の日は「明け」で休み。夜勤は2日続けない
- 週（月〜日）の勤務日数は上限まで。連続勤務は上限まで
- 「休み」の希望は必ず守る
- 勤務の回数は、週の上限に合わせて偏りなく配る

## 守ること
- 名前と勤務の条件だけを扱う。住所・電話・健康のことなどの個人情報は表に入れない（メモにも書かない）。
- シフトを従業員に配る・送るのは人がする。
- 労働時間や休日の決まりは会社の就業規則・36協定によるので、「最終の確認は社会保険労務士などに」と添える。
