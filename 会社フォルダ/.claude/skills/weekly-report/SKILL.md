# 週報の下書き

## 手順
1. 今週の範囲を決める（今週の月曜〜今日）。
2. 集める。
   - 書類台帳：受付日が今週の書類（種類ごとの件数、主な取引先）
   - 売上台帳：請求日が今週の請求（件数・合計）、入金日が今週の入金（件数・合計）、入金待ちの合計
   - やること：今週「済」にしたもの、来週が期限のもの
3. 次の形で下書きする。
   - 今週やったこと（3〜5行）
   - 数字（請求・入金・入金待ち・受け付けた書類の件数）
   - 来週やること（やること台帳の来週期限のもの）
   - 困っていること（台帳から読み取れない。空欄にして「ここに書いてください」とする）
4. 90_その他/週報_YYYY-MM-DD.md に保存し、本文も見せる。

## 守ること
- 台帳に無い出来事を作らない。数字は台帳から計算したものだけ。
