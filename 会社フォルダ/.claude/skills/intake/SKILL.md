# 書類の受付

## 手順
1. 00_受付箱 の中のファイルを一覧にする（ここに入れる.txt は除く）。0件なら「受付箱は空です」と伝えて終わる。
2. 1件ずつ中身を読み、次を決める。
   - 書類の種類：請求書／見積書／契約書／領収書／議事録／規程・マニュアル／その他
   - 取引先（CLAUDE.md の書き方の決まりに従う）
   - 書類の日付（発行日。なければ「不明」）
   - 金額（税込の合計。なければ空欄）
   - 期限（支払期限・契約の終了日・更新日など。なければ空欄）
   - 個人情報（マイナンバー・口座番号など）が含まれているか
3. 移す先を決める：請求書→10_請求書、見積書→11_見積書、契約書→12_契約書、領収書→13_領収書・経費、議事録→20_議事録、規程・マニュアル→30_規程・マニュアル、その他→90_その他。
   ただし、自社が受け取った請求書（支払うもの）は 13_領収書・経費 に入れ、メモに「支払う請求書」と書く。
4. 次の表を見せる：「元の名前 → 新しい名前 → 移す先 → 種類・取引先・日付・金額・期限」。「不明」と、個人情報を含む書類は、表の上にまとめて目立たせる。
5. 「この内容でよいですか？」と聞き、OKを待つ。直しを言われたら表を直して、もう一度見せる。
6. OKが出たら、名前を変えて移す。同じ名前があれば末尾に _2、_3 を付ける。
7. 台帳/書類台帳.csv の最後に1件1行で書き足す。列：受付日（今日）,書類の種類,取引先,書類の日付,金額,期限,ファイルの場所（会社フォルダからの相対パス）,メモ
8. 「○件を受け付けました。不明が○件あります」と報告する。

## 守ること
- 削除しない。中身を書き換えない。
- 個人情報を含む書類は移さずに残し、人に知らせる（台帳には書かない）。
