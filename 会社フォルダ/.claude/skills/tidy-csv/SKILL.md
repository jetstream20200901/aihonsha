# 表を台帳の形に直す

## 手順
1. 渡されたファイル（CSV・Excel）を読み、文字化けしていたら文字コード（Shift_JIS など）を変えて読み直す。
2. どの台帳に入れるかを決める（売上・請求の一覧 → 売上台帳、書類の一覧 → 書類台帳）。わからなければ聞く。
3. 元の列と台帳の列の対応表を見せる（例：「取引日」→「請求日」、「税込金額」→「金額」）。対応しない列は捨てずに、表で知らせる。
4. 直し方：日付は YYYY-MM-DD、金額は数字だけ（「円」「,」「¥」を外す）、取引先は CLAUDE.md の書き方の決まりに従う。
5. 先頭の5行を「直したあとの形」で見せ、OKを待つ。
6. OKが出たら台帳の最後に書き足す。台帳に同じ行（同じ日付・取引先・金額）がすでにある場合は足さずに、件数を知らせる。
7. 「○行を足しました。重複で足さなかった行が○行あります」と報告する。元のファイルは変えない。
