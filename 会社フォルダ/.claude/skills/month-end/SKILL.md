# 月末の締め

## 手順
1. 対象の月を決める（指定がなければ今月）。
2. 売上台帳：対象月に請求した件数と合計、取引先別の合計。入金日が空の行（入金待ち）を取引先・金額・入金期限で一覧にし、期限を過ぎたものに印。
3. 書類台帳：書類の日付が対象月の領収書・支払う請求書（13_領収書・経費 にあるもの）の合計を、メモや内容から「交通費・消耗品・通信費・外注費・その他」に分けて集計。分けられないものは「その他」。
4. 書類台帳とやること：翌月末までに期限が来るものを一覧に。
5. 台帳に「不明」が残っている行があれば一覧にする（締めの前に直すため）。
6. 90_その他/月末の締め_YYYY-MM.md に保存し、要点を5行で報告する。
7. 最後に「正式な帳簿・申告は、会計ソフトと税理士さんで行ってください」と添える。

## 守ること
- 台帳は読むだけで変えない。経費の分け方は目安で、税務の判断はしない。
