# 指定したフォルダを整理する

## はじめに確かめること
- 整理するフォルダは、**人がこの会話で指定したフォルダだけ**。指定がなければ「どのフォルダを整理しますか？」と聞く。
- そのフォルダの中だけで作業する。外のファイルは読まない・動かさない。
- クラウドだけに保存されていて開けないファイルがあれば、「開けないファイルが○件あります（パソコンに保存してから、もう一度）」と伝える。

## 手順
1. 指定フォルダの中のファイルを一覧にする（下の小フォルダも含める）。ファイルが200件を超えるときは、「まず○○件ずつ進めます」と伝えて、古い順に区切る。
2. 1件ずつ中身を読み、次を決める（読めないものは「不明」）。
   - 書類の種類：請求書／見積書／契約書／領収書／議事録／規程・マニュアル／写真／その他
   - 取引先（会社のルールの書き方に従う）
   - 書類の日付（発行日）
   - 金額（税込の合計）・期限（支払期限・契約の終了日など）
   - 同じ中身のファイル（重複）か
   - 個人情報（マイナンバー・口座番号・カード番号・健康情報）が含まれているか
3. 整理の案を作る。指定フォルダの中に、種類ごとの小フォルダ（例：請求書／見積書／契約書／領収書・経費／議事録／規程・マニュアル／その他）を作る案にする。
4. 次の表を見せる：「今の場所と名前 → 新しい名前 → 移す小フォルダ → 種類・取引先・日付・金額・期限」。
   表の上に、次をまとめて目立たせる：「不明」の書類／重複の疑い（どちらを残すかは人が決める）／個人情報を含む書類（動かさない）。
5. 「この内容で整理してよいですか？」と聞き、OKを待つ。直しを言われたら表を直して、もう一度見せる。
6. OKが出たら、名前を変えて移す。同じ名前があれば末尾に _2、_3 を付ける。重複の疑いのものは「重複の疑い」小フォルダに移すだけで、消さない。
7. 指定フォルダの中に「整理の記録_YYYY-MM-DD.csv」を作る（元の場所,新しい場所,種類,取引先,日付,金額,期限）。元に戻したいときに使える。
8. 会社フォルダの台帳にも入れたいか聞き、「はい」なら 台帳/書類台帳.csv に書き足す（ファイルの場所は指定フォルダからの場所で書く）。
9. 「○件を整理しました。不明○件・重複の疑い○件・個人情報を含むため動かさなかったもの○件」と報告する。

## 守ること
- 削除しない。中身を書き換えない。
- 個人情報を含む書類は動かさず、人に知らせる（台帳や記録にも中身を書かない）。
- 移す前に必ず表を見せてOKをもらう。
