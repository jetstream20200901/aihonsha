# 会計ソフトから お金の数字を取る

## 0. どこから読むか（設定.json の accounting）
- "freee"：freee の MCP（Claude にコネクタとしてつないだもの）で読む
- "moneyforward"：マネーフォワード クラウド会計の MCP で読む
- "csv"：会計データ/ フォルダに置かれた、会計ソフトから書き出したCSVを読む（弥生・その他）
- "none"（使わない）：何もしない。画面は 設定.json の口座残高と台帳から計算する
- つないだはずの MCP が見つからない・期限切れのときは、何も作らずに 台帳/判断待ち.json に「会計ソフトにもう一度つないでください（手順：会計ソフトとつなぐ手順.md）」を1件足して終わる。

## 1. 読むもの（どれも「読むだけ」）
| 項目 | freee / マネーフォワード で読むもの | CSV のとき |
|---|---|---|
| balance 口座残高 | 銀行口座（口座ごと）の残高の合計。現金・クレジットカードは入れない | 口座残高のCSV、または試算表の「普通預金」「当座預金」 |
| receivable 入金待ち | 売掛金の残高。取引先別・期日つきがあれば期日の近い順に | 売掛金の一覧CSV |
| pay30 30日以内の支払い | 未払金・買掛金のうち、期日が今日から30日以内のもの＋設定の「決まった支払い」 | 買掛金・未払金の一覧CSV |
| sales_month 今月の売上 | 今月の試算表（損益）の売上高 | 試算表CSV |
| expense_month 今月の経費 | 今月の試算表の売上原価＋販売費及び一般管理費 | 試算表CSV |
| monthly_sales | 直近12か月の売上高（月ごと） | 月次推移のCSV |

## 2. 書くもの：台帳/お金.json
```json
{"source":"freee|moneyforward|csv","synced_at":"YYYY-MM-DD HH:MM",
 "balance":数字,"receivable":数字,"receivable_items":[{"client","amount","due"}],
 "pay30":数字,"pay_items":[{"to","amount","due"}],
 "sales_month":数字,"expense_month":数字,"monthly_sales":[{"month","amount"}],
 "notes":["読めなかった所など"]}
```
- /dashboard は、お金.json の synced_at が3日以内ならこちらの数字を使い、画面に「freee から ○月○日 ○時に取得」と出す。古いときは台帳と設定の数字に戻し、「会計ソフトの数字が古い」と判断待ちに出す。

## 3. 守ること（大事）
- **会計ソフトには何も書かない**：仕訳・取引・請求書・口座の登録や変更、削除は、頼まれても行わない（会計の数字が変わるため）。必要なら「会計ソフトでこう直してください」という案を判断待ちに出すだけ。
- 口座番号・カード番号・ログイン情報は、お金.json にも台帳にも書かない（残高の数字と口座の呼び名だけ）。
- 読んだ数字と台帳（売上台帳・書類台帳）がずれていたら、どちらかを勝手に直さず、「○○が会計ソフトと台帳で○円ちがう」を判断待ちに出す。
- 取れなかった項目は null にして、推測の数字は入れない。

## 報告
「○○（会計ソフト）から取得：口座 ○円・入金待ち ○円・30日以内の支払 ○円・今月の売上 ○円（○時○分）」と短く報告する。
