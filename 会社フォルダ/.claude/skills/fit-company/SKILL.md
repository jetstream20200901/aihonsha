# 会社に合わせる（直す・足す）

## 進め方
質問は1回に1〜3個まで。答えにくいものは例を出す。わからない所は今の設定のままにする。

### 1. 会社のことを聞く
- 会社名・業種（例：工務店、美容室、税理士事務所、ネットショップ）
- 社員の人数と、このパソコンを使う人
- 締め日と、請求書の支払い期限
- よく扱う書類（例：見積書・発注書・納品書・請求書・領収書・契約書・カルテ・図面・写真）
- 今の書類の置き場所（例：デスクトップ、OneDrive、Googleドライブ、共有フォルダ）
- 毎週・毎月、手間がかかっている作業を3つ

### 2. 変える案を見せる
次の4つを表で見せ、「この内容で変えてよいですか？」と聞く。OKまで何も変えない。
1. **CLAUDE.md（会社のルール）**：会社名・業種・締め日・書類の種類と仕分け先・書き方の決まり（日付・取引先・金額）。
2. **フォルダ構成**：業種に合った仕分け先（例：工務店なら「現場写真」「図面」、美容室なら「予約・顧客メモ（個人情報に注意）」）。今あるフォルダの名前を変える案と、新しく作る案。
3. **今あるスキルの書類の種類**：intake・folder-tidy・folder-analyze の「書類の種類」と「移す先」を、1の書類の種類に合わせる。
4. **新しく足すスキル**：1の「手間がかかっている作業」ごとに、スキルの案（名前・何を頼むと動くか・手順・守ること）。

### 3. OKが出たら変える
- CLAUDE.md を書き換える（元の内容は「CLAUDE_元.md」として残す）。
- **アップデートで消えない直し方**：会社に合わせた決まりは CLAUDE.md の「## 会社だけの決まり」に書く（基本ルールと食い違うときはこちらが優先）。仕組み/AI本社の基本ルール.md・画面の HTML・キットに入っているスキルは、アップデートで新しい版に差し替わるので書き換えない
- キットのスキルを会社用に変えたいときは、そのスキルを書き換えず、別の名前（例：invoice → invoice-うち用）でコピーしてから直す。新しく足すスキルも、キットにない名前にする
- フォルダを作る・名前を変える（中身は消さない）。
- スキルを直す：直す前のファイルは同じ場所に「SKILL_元.md」として残す。
- 新しいスキルを .claude/skills/（スキル名）/SKILL.md として作る。書き方は今あるスキルと同じ形（name・description・手順・守ること）。
- 台帳の見出しは変えない（画面や他のスキルが使っているため）。列を足したいときは、最後に足す案を見せてOKをもらう。

### 4. 確かめる
- 新しいスキルごとに、練習用の小さなファイルで1回試す（本物の書類は使わない）。
- 「変えたこと」の一覧（何を・どこを・元に戻す方法）を「会社に合わせた記録_YYYY-MM-DD.md」に保存し、要点を伝える。

## 守ること
- 何かを変える前に、必ず案を見せてOKをもらう。
- 消さない。元のファイルは「_元」を付けて残す。
- 個人情報を扱う書類（顧客の名簿・カルテなど）がある業種では、置き場所と「書き写さない」決まりを CLAUDE.md に必ず書く。
- 会社のルール（CLAUDE.md）の「してはいけないこと」は、減らさない（足すのはよい）。
