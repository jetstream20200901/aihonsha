# 人事（シフトと勤務記録）

このフォルダの4つの表（CSV・UTF-8 BOM付き）を使います。見出しの名前と順番は変えないでください。
個人情報（住所・電話・生年月日・マイナンバー・口座・健康情報）は入れません。名前と勤務の条件だけを入れます。

| ファイル | 中身 | 誰が書く |
|---|---|---|
| 従業員.csv | 名前・働き方・できる勤務・週の上限・連続勤務の上限・メモ | 管理する人 |
| 勤務の型.csv | 勤務区分（日勤・夜勤など）の時間と、1日に必要な人数 | 管理する人 |
| シフト希望.csv | 「この日は休みたい」「この日は日勤だけ」などの希望 | 本人の希望を管理する人が入れる |
| 勤務記録.csv | 実際に働いた日・時間（出勤・退勤・休憩） | 毎日（または月末にまとめて） |

できあがるもの：シフト表_YYYY-MM.csv（名前×日付の表）、シフト表_YYYY-MM.html（見やすい表）、シフトの確認_YYYY-MM.md（守れなかった条件の一覧）、勤務集計_YYYY-MM.csv（1人ごとの勤務日数・時間・深夜の時間）

※労働時間・休日・深夜労働などのルールは、会社の就業規則や36協定によって違います。最終の判断は社会保険労務士などの専門家にご確認ください。
