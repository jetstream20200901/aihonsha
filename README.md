# AI本社（無料）

Claude Code で小さな会社を回すキットです。事務・経理・営業・企画の仕事を AI にまかせ、社長は「会社の画面」で判断するだけにします。すべて無料です。

## はじめ方
1. 右の **Releases** から `aihonsha.zip` をダウンロードして、すべて展開します
2. Windows は「セットアップ（Windows）.bat」、Mac は「セットアップ（Mac）.command」をダブルクリックします
3. くわしくは「はじめの30分.md」をご覧ください

## すでに使っている方（アップデート）
- 見張り番が1日1回この置き場の版を確かめ、新しい版があれば会社の画面の「判断が必要なこと」に出します。「OK」を押すと、台帳・書類・設定はそのまま、仕組み（画面・スキル・見張り番）だけが新しくなります
- 手で行うときは、新しい `aihonsha.zip` を展開して「アップデート（Windows）.bat」（Mac は「アップデート（Mac）.command」）をダブルクリックします
- どちらも、先に控え（バックアップ）を取り、最後にデータが1つも変わっていないかを確かめ、変わっていたら自動で元に戻します

## 必要なもの
- Claude の有料プラン（Pro 以上）
- Windows または Mac、Chrome または Edge

## ご注意
- 会計ソフト・税理士・社労士の代わりにはなりません
- AI はメールや請求書を外に送りません。ファイルも消しません。パスワード・口座番号・マイナンバーは台帳に書きません
